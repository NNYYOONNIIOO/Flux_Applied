# Flux_Applied

## Introduction


Flux_Applied is a mod that integrates the FE system with the AE2 network, allowing you to store FE in the network.

***

## Main Features

### FE Storage Cells

*   Multiple capacity FE storage cells: 1k, 4k, 16k, 64k, 256k, 1M, 4M, 16M, 64M, 256M, 1G
*   Compatible with AE2 drives
*   View stored FE in ME terminals

***

### FE port

*   Combines FE with AE2 network functionality
*   Occupies 1 ME channel
*   Has three modes: bidirectional, input-only, and output-only.
*   The default output rate is the upper limit of int (Integer.MAX_VALUE), configurable.

***

### ME Terminal Integration

*   Display virtual FE fluid in ME terminals
*   Quick interaction with mana containers:
    *   Left-click: Execute FE exchange (fill/extract)
    *   Right-click: Deposit item into network

***
