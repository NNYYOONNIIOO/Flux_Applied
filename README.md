# Flux Applied

Flux Applied adds Forge Energy (FE) storage and transfer to Applied Energistics 2 networks.

## Features

- FE storage cells in capacities from 1k to 1G, usable in AE2 drives and terminals.
- FE network ports, energy import buses, energy storage buses, and interface upgrade cards.
- Terminal item-resource interactions provided by Terminal Interaction Integration.
- Optional Jade tooltips show energy, device status, transfer modes, and import rates.
- Long-valued transfer rates for native Flux Applied storage; Forge energy capabilities are handled through bounded integer-sized transfers.

## Requirements

- Minecraft 1.16.5
- Forge 36.2.42
- Applied Energistics 2 8.4.7
- Terminal Interaction Integration 1.2.4-1.16.5
- Jade 2.8.x (optional, replaces The One Probe integration)
- Java 8 to build

Build with `gradlew.bat build` from a Java 8 environment.
